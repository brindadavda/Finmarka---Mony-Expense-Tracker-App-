📱 Money Tracker App – Full Requirements ( APP Name -> Finmarka )

Platform: Android
Tech Stack: Kotlin, Jetpack Compose
Backend: ❌ None (offline-first)
Database: Room (SQLite)
Architecture: MVVM
Min SDK: 24+

1️⃣ App Overview

A personal finance app that allows users to:

Track income & expenses

Organize by categories

Set budgets

View reports & charts

Keep data private & offline

No login. No cloud dependency.

7️⃣ Database Design (Room)
7.1 TransactionEntity
@Entity
data class TransactionEntity(
    @PrimaryKey(autoGenerate = true) val id: Int,
    val amount: Double,
    val type: String, // INCOME / EXPENSE
    val categoryId: Int,
    val date: Long,
    val note: String?,
    val paymentMode: String
)

7.2 CategoryEntity
@Entity
data class CategoryEntity(
    @PrimaryKey(autoGenerate = true) val id: Int,
    val name: String,
    val type: String // INCOME / EXPENSE
)

7.3 BudgetEntity
@Entity
data class BudgetEntity(
    @PrimaryKey(autoGenerate = true) val id: Int,
    val categoryId: Int,
    val limitAmount: Double,
    val month: Int,
    val year: Int
)
